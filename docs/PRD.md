# Plenty Barber PRD

## Product

Plenty Barber is a premium web app that helps beauty businesses generate
professional AI-assisted visagism reports from a client photo.

## Users

- Super Admin: GoPlenty Global operator.
- Business Owner: manages business, billing, credits and team.
- Operator or Stylist: creates clients and reports.
- Final Client: receives PDF or shared report link.

## MVP Scope

- Landing page
- Login
- Protected dashboard
- Client management
- Report generation flow
- Credit validation
- AI report JSON
- PDF generation
- WhatsApp sharing
- Stripe checkout and verified webhook
- Admin panel

## Non-Goals For Phase 1

- Real authentication
- Real AI generation
- Stripe payments
- PDF rendering
- WhatsApp delivery automation
